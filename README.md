# sl-economy-mcp

An unofficial [MCP](https://modelcontextprotocol.io) server that lets Claude and other AI assistants fetch live, official Sri Lankan economic data from the [Central Bank of Sri Lanka](https://www.cbsl.gov.lk) (CBSL).

**Status:** early development. A full README comes with version 1.

## Tools

| Tool | What it returns |
| --- | --- |
| `get_snapshot` | Overnight policy rate, CCPI inflation, USD/LKR TT buying and selling rates |

Every answer includes the source URL and the time the data was fetched.

## Disclaimer

Unofficial. Not affiliated with or endorsed by the Central Bank of Sri Lanka. Data is read from CBSL's public website and may contain errors. Not investment advice.
